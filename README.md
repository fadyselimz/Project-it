# Cafrour 🛒
An e-commerce web app for Electronics, Fashion, Books & Grocery.

## Features
- User registration & login (localStorage-based)
- Product browsing across 4 categories
- Add to cart / remove items
- Checkout with Visa or Cash on Delivery
- Contact form
- Arabic tagline on homepage

## How to Run
1. Clone the repo
2. Open `login/login.html` in your browser
3. Sign up, then browse!

## Tech Stack
HTML5 · CSS3 · Vanilla JavaScript · localStorage

## ⚠️ Note
This is a frontend-only demo. Passwords are stored in localStorage — not suitable for production without a real backend.
